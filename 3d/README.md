# Modelos 3D

| Modelo | Uso |
| --- | --- |
| Case | Caixa do MacroPlay |
| Colmeia (keyguard) | Placa com furos sobre as teclas que evita toques acidentais |
| Keycaps táteis | Teclas com relevo ou braille para pessoas com deficiência visual |

Publique junto o arquivo editável (STEP ou o projeto original) e o STL pronto para imprimir.

O modelo 3D da placa montada, útil para desenhar o case, está em [`hardware/MacroPlay/MacroPlay.step`](../hardware/MacroPlay/MacroPlay.step).
